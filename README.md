# Tianyi Wu — Personal Website

English is the default language on every page load. Use EN / 中文 to switch.

## Preview
Open index.html in a browser. No installation or build is required.

## GitHub Pages
Copy index.html, style.css, app.js, .nojekyll and the assets folder to the root of the existing website repository, preserving the folder structure. In repository Settings → Pages, select the branch and root directory used by your current site. The ZIP contains a containing folder: upload its contents, not the containing folder itself.

## Content
Based on Tianyi_Wu_CV_2027_Fall.docx dated 14 November 2026. The download button points to that Word CV. Original English publication titles and venue names remain unchanged in Chinese mode. Manuscripts are explicitly marked as under review.

Google Fonts is optional; local system fonts provide a fallback. All interactions and essential assets work without third-party scripts.
